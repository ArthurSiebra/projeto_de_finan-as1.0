# projeto_de_finan-as1.0

# 💰 Sistema de Gestão Financeira Pessoal (Java + JavaFX)

Projeto de aplicação desktop para controlo de finanças pessoais, desenvolvido durante o curso avançado de **Java** do **Capacita Brasil**.

O projeto aplica na prática conceitos fundamentais de **Programação Orientada a Objetos (POO)** combinados com o desenvolvimento de interface gráfica (**GUI**) moderna e responsiva.

---

## 🛠️ Tecnologias Utilizadas

* **Java**: Lógica da aplicação e Programação Orientada a Objetos (POO).
* **JavaFX**: Construção da interface gráfica de utilizador (GUI).
* **CSS**: Estilização e personalização visual dos componentes gráficos.

---

## 🎯 Objetivos do Projeto

* Consolidação de conceitos de POO (Encapsulamento, Herança, Polimorfismo, Abstração).
* Prática de desenvolvimento de telas e gestão de eventos com JavaFX.
* Organização de código e separação de responsabilidades.
